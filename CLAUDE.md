## Что это
Персональное local-first PWA для питания и тренировок на iPhone: один пользователь, русский интерфейс, без сервера и входа.
Позже возможно публичное приложение (роли тренер/спортсмен, бесплатная и премиум-часть) — сейчас собирается максимальный набор функций.

## Как работать с владельцем
- Он не программист: технические решения принимай сам, приноси готовый проверенный результат.
- Тестирует на своём iPhone, присылает скриншоты и нумерованные списки правок — отвечать по номерам.
- Никаких заглушек и неработающих кнопок; ограничения называть честно.
- Данные на телефоне нельзя терять: изменения схемы только через миграцию (`SCHEMA_VERSION` + Dexie).

## Команды
```
npm install
npm run check          # типы + линтер границ + тесты — зелёным перед коммитом
npm run seed:validate  # проверка каталога упражнений/продуктов
npm run dev / build    # apps/web
```
Деплой: пуш в `main` → GitHub Actions → GitHub Pages (`apps/web/dist`). Коммиты от имени `Claude <noreply@anthropic.com>`.

## Устройство
Слои (зависимости только сверху вниз, границы проверяет ESLint и `tests/boundaries.test.ts`):
```
apps/web -> packages/application -> packages/domain
apps/web -> packages/storage-local (только через src/composition) -> packages/domain
packages/seed -> packages/domain
```
Подробно: `docs/ARCHITECTURE.md` (принципы, план/факт, версии программы, прогрессия с RIR, боль, расписание), `docs/STAGES.md` (этапы).
Экраны: `apps/web/src/screens` — Today, Nutrition, Training, Progress, Profile, Cycle, Cardio, каталог упражнений, сканер штрихкодов, импорт Excel и др.

## Связанное
- MY WORLD (путешествия) вынесен в отдельный репозиторий TSAGA7/myworld; в `apps/web/public/world/` — только переадресация и sw.js, удаляющий старые кэши. Не трогать.
- Личная программа владельца (рекомпозиция, 3 тренировки в неделю, Excel-трекер) — исходные данные для приложения.
