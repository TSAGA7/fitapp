# Этапы разработки

1. **Foundation** — репозиторий, пакеты, линтер границ, модель и Zod-схемы, порты, формат каталога. ✅
2. **Domain engines** — калории, БЖУ, рацион, граммовки, прогрессия (RIR), анализ веса/замеров/тренировок. Чистые функции + золотые тесты из Excel.
3. **Dexie + backup + импорт Excel** — хранилище, миграции, экспорт/импорт JSON, импортёр Excel (preview → валидация → импорт), `persist()`.
4. **Профиль и прогресс** — онбординг, цели, замеры, графики веса и замеров.
5. **Питание** — продукты (сырой/готовый/как продаётся), планировщик, план/факт, «Переделать».
6. **Планирование тренировок** — каталог ~80 упражнений, ограничения, оборудование, расписание, версии и proposals, перенос тренировки.
7. **Режим тренировки** — plannedSets, факт, RIR, пропуски, боль, ручная замена упражнения, прогрессия.
8. **Аналитика и версионирование** — сводки, история версий, анализ тренировок.
9. **PWA и надёжность на iPhone** — офлайн, обновления, установка, хранилище, доступность.
